PENJELASAN APLIKASI
QR CODE GENERATOR & MANAGER BERBASIS WEB
UNTUK GELAR KARYA GURU INFORMATIKA

1. Nama dan Profil Aplikasi

Aplikasi ini bernama "QR Code Generator & Manager". Aplikasi berbasis web tersebut dirancang untuk membuat, mengelola, mengunduh, dan mencetak QR Code berukuran presisi 10 x 10 cm. Aplikasi dapat digunakan langsung melalui browser tanpa proses instalasi program.

Aplikasi dikembangkan untuk mendukung layanan informasi dan administrasi digital di SMP Negeri 90 Jakarta. Aplikasi ini diciptakan oleh Turino Hadisaputro dan memanfaatkan teknologi web modern, QR Code, kanvas digital, serta database SQLite di browser.


2. Latar Belakang

Perkembangan teknologi digital menuntut sekolah memiliki sarana yang cepat, praktis, dan mudah diakses oleh warga sekolah. QR Code dapat menjadi jembatan antara media cetak dan layanan digital. Pengguna cukup memindai QR Code dengan kamera ponsel untuk membuka tautan tertentu, seperti situs layanan, formulir, presensi, atau dokumen sekolah.

Namun, pembuatan QR Code dengan logo sekolah serta pencetakan dalam ukuran yang konsisten sering memerlukan aplikasi berbayar atau proses manual yang rumit. Oleh karena itu, dikembangkan aplikasi yang dapat menghasilkan QR Code profesional, menyimpan riwayat desain, dan mencetaknya secara presisi dalam satu tampilan.


3. Tujuan Aplikasi

Tujuan umum aplikasi adalah menyediakan sarana pembuatan QR Code yang praktis, aman, fleksibel, dan dapat digunakan secara mandiri oleh guru atau tenaga kependidikan.

Tujuan khusus aplikasi adalah:
a. Mempermudah penyediaan akses menuju laman atau data digital sekolah.
b. Menyediakan QR Code dengan identitas visual SMP Negeri 90 Jakarta.
c. Menghasilkan gambar berkualitas tinggi untuk cetak berukuran 10 x 10 cm.
d. Mengelola riwayat URL, label, dan desain QR Code.
e. Mendukung dokumentasi serta proses pengarsipan menggunakan database SQLite.
f. Menjadi contoh pemanfaatan teknologi informatika untuk penyelesaian masalah nyata di sekolah.


4. Fungsi Utama Aplikasi

A. Membuat QR Code
Pengguna memasukkan alamat URL atau teks, kemudian aplikasi mengubah data tersebut menjadi matriks QR Code. Perubahan tampilannya dapat dilihat langsung pada area preview.

B. Menambahkan Logo
Aplikasi menyediakan logo preset SMP Negeri 90 Jakarta dalam bentuk SVG dan memungkinkan pengguna mengunggah logo lain. Ukuran logo dapat diatur antara 15 persen hingga 28 persen dari luas QR Code.

C. Mengatur Tampilan
Pengguna dapat menampilkan atau menyembunyikan tulisan "SCAN ME", menampilkan atau menyembunyikan URL, serta memilih tingkat koreksi kesalahan QR Code. Tingkat koreksi High direkomendasikan karena mampu memperbaiki bagian kode hingga sekitar 30 persen dan aman digunakan bersama logo.

D. Menyimpan Data ke SQLite
Aplikasi menggunakan SQL.js berbasis WebAssembly. Label, URL, waktu penyimpanan, dan informasi penggunaan logo dapat disimpan pada database SQLite yang berjalan di dalam browser.

E. Mengelola Riwayat
Pengguna dapat melihat daftar arsip, memuat kembali arsip ke editor, menghapus arsip, mengekspor database menjadi file .sqlite, serta mengimpor file database SQLite yang sudah disimpan.

F. Mengunduh dan Mencetak
QR Code dapat diunduh dalam format PNG beresolusi 1200 x 1200 piksel dan dicetak pada kertas berukuran 10 x 10 cm. Pengaturan cetak direkomendasikan menggunakan Margins: None dan ukuran kertas 100 x 100 mm.


5. Teknologi yang Digunakan

1. HTML sebagai struktur halaman.
2. Tailwind CSS sebagai kerangka tampilan antarmuka.
3. JavaScript sebagai pengendali proses aplikasi.
4. Library qrcode-generator untuk membentuk matriks QR Code.
5. HTML Canvas untuk menggambar QR Code, logo, dan teks pada resolusi tinggi.
6. SQL.js untuk menjalankan SQLite melalui WebAssembly di browser.
7. Font Awesome dan Google Fonts untuk ikon serta tipografi.
